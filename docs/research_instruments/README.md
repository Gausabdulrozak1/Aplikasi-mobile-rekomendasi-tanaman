# Research Instruments

All files in this directory are blank instruments. They contain question/test
definitions only and no respondent identity, answer, score, signature, expert
approval, interview result, observation result, or UAT claim.

Use informed consent before collecting personal data. Assign coded respondent
IDs in analysis files and keep signed consent forms outside the public
repository. Automated fixture results belong in `docs/testing`, not in these
human-research sheets.
