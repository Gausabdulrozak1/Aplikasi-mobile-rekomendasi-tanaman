# Evaluation Artifacts

Folder ini menyimpan template evaluasi yang aman untuk Git.

Hasil evaluasi nyata dari Colab boleh disalin ke sini hanya jika ukurannya kecil
dan tidak berisi model besar. File gambar hasil generasi sebaiknya tetap berada
di Google Drive atau folder `artifacts/evaluation/generated/` yang diabaikan Git.

Artefak yang perlu dikumpulkan untuk Bab IV:

- manifest generasi;
- contact sheet base model versus LoRA;
- CSV penilaian manusia;
- ringkasan eksperimen;
- screenshot runtime Colab, checkpoint, dan file `.safetensors`.
